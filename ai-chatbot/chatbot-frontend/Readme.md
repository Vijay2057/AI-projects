### Go to projects
```
cd D:\projects
```

### Create React application
```
npm create vite@latest chatbot-ui
```
When prompted:

Select React.
Select TypeScript.

### Install dependencies

Move into the project:
```
cd chatbot-ui
```

Install the base dependencies:
```
npm install
```

Then install the libraries we'll eventually use:
```
npm install react-router-dom
```


### Run app using command
```
npm run dev
```
